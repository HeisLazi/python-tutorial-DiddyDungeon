# Quest Lab Combat System — Historical Proposal

**Status: RETIRED / superseded by `COMBAT_SYSTEM.md` and ruleset 1.4.0.**

This file is retained so the design history is not erased.

The approved direction changed during discussion and is now canonical in:

- `CANON_LEDGER.md` ruleset `1.4.0`;
- `COMBAT_SYSTEM.md`.

Key approved changes from the older proposal:

- no mechanical weapon-damage slot;
- offense is verified **Impact** against enemy **Resolve**;
- armor is percentage-based protection against failed submitted Battle actions;
- weapon-shaped items such as scythes/swords/staffs may exist as **trinkets** with special effects;
- ordinary learning/debugging remains completely damage-free;
- weekly bosses are planned as shared software-project raids with predefined objective Impact and party-first clears.

Do not implement rules from an older version of this proposal when they disagree with the canonical combat specification.
