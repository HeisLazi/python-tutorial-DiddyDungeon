# Castle layout prototype

This is an isolated Godot experiment, not the playable Home. It uses copies of existing game art as placeholders to test room scale, four-direction movement, Pyr following and a floor-plan HUD. Great Hall connects west to Library; Library connects north to Gallery. The doors work both ways. The stations are labels only; there is no save, upgrade, or real Tutor/Forge integration.

From the repository root run `sh tools/build_castle_prototype.sh`, then serve `ide/castle-prototype/export` over HTTP and open it in Chromium. Click the game and use arrow keys or WASD. The asset copies and web export are generated and ignored. This prototype is not a finished hunter or castle art redesign.
