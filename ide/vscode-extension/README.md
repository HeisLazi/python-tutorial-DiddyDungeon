# Quest Lab VS Code Extension (scaffold)

## Install (dev)
1. Open this folder in VS Code: `ide/vscode-extension`
2. Run `npm install` (none needed, no deps)
3. Press F5 to launch Extension Development Host
4. Run command: "Quest Lab: Start Backend"
5. Run command: "Quest Lab: Open Dashboard"

## Notes
- The dashboard webview loads `http://localhost:5173` (Vite dev server).
- For production, bundle the built frontend into the extension.
- This is a minimal scaffold; expand as needed.
