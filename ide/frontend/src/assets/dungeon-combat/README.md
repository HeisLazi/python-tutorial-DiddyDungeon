# Dungeon combat art

The side-view Tate sheet is copied from `ide/home-godot/art/hunter_side.png`.
The wraith is original image-generated placeholder art based on the project's
hunter and the supplied Castlevania style references. The String Mimic,
Forked Path and Mimic Matriarch are original image-generated concepts using
those references and the wraith; their transparent source images are in
`tools/home_art/concepts/combat/`. Their in-game copies are thresholded and
nearest-neighbor scaled to 36, 44 and 56 pixels tall, respectively.

The crypt was generated using the actual Home screenshot and concept for
palette and architecture, then reduced to 320×180. Enemies without dedicated
art still use the wraith placeholder, and every location uses the same crypt.
