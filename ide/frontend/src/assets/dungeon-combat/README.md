# Dungeon combat art

The side-view Tate sheet is copied from `ide/home-godot/art/hunter_side.png`.
The wraith is a temporary original image generated from the project's hunter
and the supplied Castlevania style references. The crypt is an original image
generated using the actual Home screenshot and Home concept for palette and
architecture, then reduced to 320×180 for this preview. The same placeholder enemy and crypt are used for every encounter until
creature-specific artwork and region-specific arenas are designed.
