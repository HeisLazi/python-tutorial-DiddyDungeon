# Quest 04 — Casino / Slots

## Mission
Build a terminal casino game centred on slots and a simple bankroll system.

## Main skills
- `random`
- lists
- dictionaries
- functions
- loops
- probability thinking
- numeric state

## Core requirements
- player starts with a bankroll
- player chooses a bet amount
- reject impossible/invalid bets
- spin 3 symbols chosen randomly
- calculate payouts for different combinations
- update bankroll after each spin
- end when the player quits or reaches 0
- show session wins/losses clearly

## Mobs
1. **Coin Rat** — track bankroll.
2. **Spin Imp** — generate three symbols.
3. **Payout Mimic** — reward different combinations correctly.
4. **Debt Ghoul** — block invalid bets.
5. **Greed Spirit** — keep the game running across many spins.

## Boss — Lady Luck
Add at least one second casino game or special mechanic, such as high/low, dice, jackpot meter, or risk-it double-or-nothing.

Then explain to PYR:
- where randomness enters the program;
- how bets are validated;
- how payouts affect bankroll;
- why your loop eventually ends.

## Optional loot
- weighted symbols
- jackpot
- session statistics
- lucky streak messages
- shop/cosmetic flavour bought with fake coins

## Safety / scope
This is a programming exercise using fake points only. Do not connect it to real gambling, payments or betting services.

## PYR rule
Help Lazarus reason about probabilities and state. Do not write the payout table or full spin loop for him.
