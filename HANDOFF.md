# Quest 00 — Rock Paper Scissors Tournament

## Mission
Build a terminal Rock Paper Scissors tournament from scratch using only fundamentals.

## Main skills
- `if / elif / else`
- loops
- functions
- lists
- `random`
- keeping score in variables

## Core requirements
- player chooses rock, paper or scissors
- computer chooses randomly
- program decides each round correctly
- invalid input does not crash the game
- first player to a target score wins the match
- show round number and score
- allow a rematch without restarting Python

## Mobs
1. **The Mimic** — get one round working.
2. **The Loop Imp** — make rounds repeat.
3. **The Score Thief** — track wins correctly.
4. **The Trickster** — handle bad input.

Each mob is a meaningful milestone, not just a line of code.

## Boss — The Pattern Warden
Add a tournament mode such as best-of-3 / best-of-5 or first-to-N, then explain to PYR:
- how the winner logic works;
- what keeps the game loop running;
- where the score changes;
- why invalid input does not break the program.

If you can answer those and the game works, the boss is defeated.

## Optional loot
- win/loss streaks
- match history stored in a list for the current run
- fun combat text for different outcomes
- a simple computer personality that taunts based on score
