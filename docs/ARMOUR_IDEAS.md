# Future armour directions

Ideas from Lazi for a later armour art and progression slice. These are not implemented equipment.

- Explore armour inspired by historical Norse and Roman equipment, and by specific East African cultures and periods. Research the actual garments, materials and construction before designing; do not flatten a region into one generic costume.
- Give sets distinct shapes and identities, with silhouettes that read at combat sprite size. Where appropriate, develop upgraded tiers that visibly evolve the same set.
- Include playful cosmetic sets too, such as a banana skin. Cosmetic humour can coexist with the gothic pixel-art style.
- Show the hunter wearing the selected set, with the existing weapon-specific idle, attack and hurt animations supported. Avoid substituting generic coat icons or static concepts for finished wearable sprites.
- Decide how each set is earned when it is designed, preserving meaningful sources across crafting, bosses and other modes.
